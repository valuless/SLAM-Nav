# Robot Navigation

[中文文档](README_zh.md)

A ROS 2 autonomous navigation workspace integrating LiDAR drivers, LiDAR-inertial odometry, mapping, Nav2, map conversion tools, and Dobot Atom robot control.

## Workspace Layout

```text
robot-navigation/
├── src/
│   ├── FAST_LIO/                 # LiDAR-inertial odometry
│   ├── navigation2/              # Nav2 source tree
│   ├── navigation/               # Project launch and navigation configuration
│   ├── ground_reset/             # Ground-plane calibration and reset
│   ├── pcd2pgm/                  # PCD to occupancy-grid conversion
│   ├── rslidar_sdk/              # RoboSense LiDAR SDK and ROS integration
│   ├── rslidar_msg/              # RoboSense message definitions
│   ├── rs_to_velodyne_ros2/      # RoboSense-to-Velodyne point-cloud adapter
│   ├── livox_ros_driver2/        # Livox ROS 2 driver
│   ├── Livox-SDK2/               # Livox SDK
│   ├── dobot_atom/               # Dobot Atom ROS 2 message definitions
│   ├── dobot_atom_bridge/        # ROS 2 to Dobot RPC bridge
│   └── dobot_atom_sdk/           # Official SDK Git submodule
├── build/                        # Generated by colcon, not tracked
├── install/                      # Generated by colcon, not tracked
└── log/                          # Generated by colcon, not tracked
```

## Main Components

| Area | Packages | Purpose |
|---|---|---|
| LiDAR | `rslidar_sdk`, `rslidar_msg` | RoboSense LiDAR driver and messages |
| LiDAR | `livox_ros_driver2`, `Livox-SDK2` | Livox LiDAR driver and SDK |
| Adaptation | `rs_to_velodyne_ros2` | Converts RoboSense point clouds to a Velodyne-compatible format |
| Localization | `FAST_LIO` | Tightly coupled LiDAR-IMU odometry |
| Navigation | `navigation`, `navigation2` | Project launch configuration and the Nav2 stack |
| Mapping | `pcd2pgm` | Converts PCD maps to PGM/YAML occupancy grids |
| Calibration | `ground_reset` | Ground-plane calibration and pose reset |
| Dobot | `dobot_atom` | ROS 2 interface definitions |
| Dobot | `dobot_atom_bridge` | Bridges ROS 2 velocity, FSM, and upper-limb commands to the official SDK |
| Dobot | `dobot_atom_sdk` | Official Dobot Atom SDK, managed as a Git submodule |

## Requirements

- Ubuntu 22.04
- ROS 2 Humble Hawksbill
- `colcon` and `rosdep`
- CMake 3.8 or newer
- Eigen3 and PCL
- Network access to the selected LiDAR and Dobot Atom robot

## Clone and Build

Clone the repository with its submodules:

```bash
git clone --recurse-submodules \
  https://gitee.com/valuless/robot-navigation.git
cd robot-navigation
```

If the repository was cloned without submodules:

```bash
git submodule update --init --recursive
```

Install ROS dependencies and build from the workspace root:

```bash
rosdep install --from-paths src --ignore-src -r -y
colcon build --symlink-install
source install/setup.bash
```

## Usage

### Start the navigation system

```bash
ros2 launch navigation system.launch.py
```

### Convert a PCD map to PGM/YAML

```bash
ros2 launch pcd2pgm pcd2pgm.launch.py
```

### Convert RoboSense point clouds to Velodyne format

```bash
ros2 launch rs_to_velodyne_ros2 convert.launch.py
```

### Start the Dobot Atom bridge

```bash
ros2 launch dobot_atom_bridge atom_bridge.launch.py \
  rpc_ip:=192.168.8.234 \
  rpc_port:=51234
```

The bridge exposes the following primary ROS 2 interfaces:

- `/cmd_vel`
- `/fsm_cmd`
- `/fsm_state`
- `/connection_state`
- `/upper_limb_cmd`
- `/upper_limb_service`

## LiDAR Configuration

Select the driver and FAST-LIO YAML file that match the connected sensor. A configuration for another model may start successfully when its point-cloud layout is compatible, but incorrect scan rate, timestamp unit, line count, or extrinsic parameters can reduce localization accuracy without causing an immediate error.

Sensor-specific FAST-LIO configurations are located under `src/FAST_LIO/config/`.
